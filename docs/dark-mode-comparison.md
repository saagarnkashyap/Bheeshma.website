# Compare the two dark editions

Both dark designs are available on every page. The header has **Dark 1** and **Dark 2** buttons; on smaller screens, open the menu to find them. Switching keeps the current page, chapter, and verse. Bookmarks and reading progress are shared.

- Dark 1: https://bheeshma.vercel.app/?dark=1 — the design from before `design/dark-mode-reimagined`.
- Dark 2: https://bheeshma.vercel.app/?dark=2 — the reimagined design.

The selected design is saved in the browser, and the `dark` URL parameter makes a comparison link shareable. Light Mode retains its existing appearance. Zen Mode uses the same reader from either dark design.

The Git tag `pre-dark-mode-reimagined` identifies the exact pre-redesign source at commit `715eedb` if a full code rollback is ever needed.
